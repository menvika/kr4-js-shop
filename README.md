## JavaScript-файлы

Скрипты подключены обычными тегами `<script defer>` в порядке зависимостей, общие функции доступны во всех файлах.

| Файл | За что отвечает |
| --- | --- |
| `data.js` | массив `products` (11 свойств у каждого товара), список категорий `categories`, промокоды, функции `getProductById`, `getCategoryLabel` |
| `utils.js` | `createElement` (безопасное создание узлов), работа с `localStorage` (`loadFromStorage`, `saveToStorage`), `formatPrice`, `pluralize`, `showToast`, `createProductPicture` |
| `catalog.js` | `createProductCard`, поиск, фильтры, сортировка, пагинация, пустое состояние, `initCatalogPage`, `initHomePage` |
| `cart.js` | корзина, расчёт суммы через `reduce`, промокоды, сохранение в `localStorage`, страница `cart.html` |
| `favorites.js` | избранное и его сохранение |
| `theme.js` | тёмная тема и её сохранение |
| `modal.js` | модальные окна на `<dialog>`, окно «Подробнее» с данными товара |
| `validation.js` | правила проверки полей, вывод ошибок на страницу, общий список ошибок |
| `product.js` | страница товара по параметру `?id=` и блок «Похожие букеты» |
| `order.js` | сценарий формы заявки и формы обратной связи, имитация отправки |
| `main.js` | общая инициализация: единый обработчик кнопок `data-action`, меню, FAQ, запуск кода нужной страницы |

Каждая `init...`-функция сначала проверяет, есть ли на странице нужные ей элементы, поэтому скрипты не падают на других страницах.

## Массив товаров

В `js/data.js` лежит массив из **8 товаров** с одинаковой структурой:

```js
{
  id: 1,                 // уникальный номер
  title: 'Весенний букет',
  category: 'mixed',     // mono | mixed | basket — совпадает со значениями фильтра
  price: 7200,           // число, не строка
  isAvailable: true,
  rating, reviews, badge, description, specs, image   // дополнительные свойства
}
```

Список категорий для фильтра строится из того же массива `categories`, поэтому значения `product.category` и `option value` совпадают автоматически.

## Реализованные функции

- Карточки товаров создаются в JavaScript (`createElement`, `textContent`, `classList`, `append`).
- Поиск по названию, фильтр по категории, цене и наличию, сортировка, счётчик найденных товаров, пустое состояние.
- Корзина, избранное, промокоды, пагинация, тёмная тема, модальное окно товара.
- Форма заявки с проверкой и имитацией отправки.

### Поиск

Поле «Поиск по названию» слушает событие **`input`**: список обновляется при каждом символе. Запрос приводится к нижнему регистру (`ё` = `е`), каждое слово запроса должно встретиться в названии (`matchesQuery`). Запрос «роз» найдёт «Розовый букет» и «Моно-букет кустовых роз».

### Фильтрация

Категория (`<select>`), «Только в наличии», «Только избранное» реагируют на событие **`change`**, поля цены «От/До» — на `input`. Если «От» больше «До», показывается подсказка, и диапазон не применяется. Любое изменение возвращает на первую страницу. Состояние фильтров записывается в адрес страницы (`catalog.html?q=роз&sort=price-asc`), и ссылку можно отправить.

### Сортировка

Варианты: по умолчанию, цена по возрастанию и убыванию, название А–Я и Я–А, рейтинг. Сортируется **копия** массива (`[...items].sort(...)`), поэтому исходный порядок `products` не меняется.

### Валидация формы

Поля в HTML помечены `data-validate="..."`. Форма с `novalidate`, обработчик `submit` вызывает `preventDefault()` и проверяет поля. Правила в `validation.js`:

- **имя** — от 2 символов, только буквы, пробел и дефис;
- **e-mail** — формат `name@example.ru` (поле необязательное в заявке, обязательное в обратной связи);
- **телефон** — цифры, `+`, скобки и дефис; 10 цифр или 11 цифр с 7/8 в начале;
- **количество** — целое от 1 до 20;
- **дата доставки** — не раньше сегодняшнего дня;
- **адрес** — обязателен только при доставке курьером;
- **комментарий** — до 300 символов (со счётчиком);
- **согласие** — обязательный чекбокс.

Ошибки показываются под полем (`aria-invalid`, `aria-describedby`) и общим списком «Проверьте форму» со ссылками на поля. Пустое поле не ругается до первой отправки. После исправления ошибка пропадает сразу. `alert()` нигде не используется. Когда всё верно, появляется блок «Заявка подготовлена».

### Безопасный вывод данных

`innerHTML`, `outerHTML` и `insertAdjacentHTML` в проекте **не используются**. Все тексты (названия, ошибки, значения формы, запрос поиска, данные из `localStorage` и адреса) попадают на страницу через `textContent` или `setAttribute`. Данные из `localStorage` считаются недоверенными: корзина, избранное и промокод проверяются при чтении (существующий `id`, целое количество от 1 до 20, известный промокод). Inline-обработчиков (`onclick` и т. п.) в HTML нет — всё подключено через `addEventListener`.

## Самостоятельные доработки

1. **Корзина** — добавление из карточки, окна и страницы товара, изменение количества, удаление, очистка в два шага (без `confirm()`), счётчик в шапке.
2. **Расчёт через `reduce`** — количество, сумма и скидка в `cart.js` (`getCartCount`, `getCartSubtotal`).
3. **Промокоды** — `SPRING10` (−10%) и `FLOWERS500` (−500 руб., от 5000 руб.). Скидка пересчитывается при изменении корзины.
4. **`localStorage`** — корзина, промокод, избранное и тема; чтение с проверкой данных и `try/catch`.
5. **Избранное** — кнопка-сердечко, счётчик, фильтр «Только избранное».
6. **Пагинация** — по 6 товаров на странице (`slice`), номер страницы в адресе.
7. **Тёмная тема** — кнопка в шапке, `data-theme` на `<html>`, учитывает системную настройку; маленький скрипт в `<head>` ставит тему до отрисовки.
8. **Форма** — имитация отправки (`setTimeout`), блокировка кнопки, состав заказа из корзины, итоговая карточка, очистка корзины после заказа, скрытие адреса при самовывозе.
9. **Пустые состояния и UX** — расширенное пустое состояние каталога (сброс фильтров и быстрый выбор категории), пустая корзина, «Товар не найден», бейджи «Хит / Новинка / Нет в наличии», рейтинг, наличие, счётчики.
10. **Модальное окно товара** на `<dialog>` (Esc, клик по фону, фокус).
11. **Страница товара** строится по `?id=` с таблицей характеристик и «Похожими букетами».

## Как проверить

1. **Каталог:** открыть `catalog.html`, ввести «роз» (2 товара), выбрать категорию «Моно-букеты» (3), включить сортировку по цене, ввести «zzz» (пустое состояние и кнопка сброса).
2. **Корзина:** добавить товары кнопкой с корзиной, открыть `cart.html`, изменить количество, ввести `SPRING10`, обновить страницу — корзина сохранится.
3. **Избранное и тема:** нажать сердечко, включить фильтр «Только избранное»; переключить тему кнопкой в шапке и перезагрузить страницу.
4. **Форма:** на `order.html` нажать «Отправить заявку» с пустой формой, затем ввести неверные e-mail и телефон, затем корректные данные.
5. **Безопасность:** открыть `catalog.html?q=<img src=x onerror=alert(1)>` — текст выводится как текст.
6. **Консоль:** DevTools → Console на всех страницах — ошибок нет.
